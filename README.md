# Project_1_TicTacToe
Tic Tac Toe Project for COMP 120

This project is a simple tic-tac-toe game where a human player goes against a computer with randomized selection. Because of this, the computer does not make very smart moves as you may realize. 

# How to Compile and Run:
To compile run the command:
gcc project1.c -o project1
Then to run the code:
./project1

After you have done that just follow the instructions in the terminal and enjoy your gameplay.

# How to play:

- As the user you will go first, you are the "O" player respectively.
- The program will show you a grid that is numbered from 0-8.
- From there you will input a number from 0-8 to select your move
- The computer will then take its turn and the new updated board will be displayed.
- This will be repeated until there is a winner or until all turns have been taken and the game ends in a draw.
- The program will then ask if you would like to play again and will repeat until you would like to quit.

# Features:

This program features:
- Automatic computer moves.
- Automatic winner detection.
- Input validation that prevents out-of-range moves, occupied positions, and non-numeric inputs.
- 3x3 visual grid so the player can make moves easily.
